
# 🧠 Deep Network Development: Assignment - Image Classification with CNN

This repository contains the final assignment submitted for the **Deep Network Development (DND)** course. The project focuses on implementing and training a Convolutional Neural Network (CNN) for image classification tasks.

---

## 📘 Project Overview

- **Course**: Deep Network Development (DND)
- **Assignment Goal**: Build and train a CNN model to classify images
- **Notebook**: `DND_Assignment_final_Sazid.ipynb`

The assignment demonstrates the end-to-end process of designing, training, and evaluating a deep learning model using convolutional layers for visual data.

---

## 🧠 Features

- Data loading and preprocessing using torchvision
- CNN model built using PyTorch
- Training loop with accuracy and loss tracking
- Evaluation on test data
- Visualization of performance metrics
